Common Oracle → PostgreSQL type mappings and syntax changes.
NUMBER(p,s) → NUMERIC(p,s)
NUMBER(p) / INTEGER → INTEGER / BIGINT
VARCHAR2(n) → VARCHAR(n)
NVARCHAR2 / NCHAR → VARCHAR / CHAR (UTF-8 default)
DATE → TIMESTAMP (Oracle DATE includes time)
CLOB / NCLOB → TEXT
BLOB → BYTEA
RAW(n) → BYTEA
XMLTYPE → XML
BINARY_FLOAT/DOUBLE → REAL / DOUBLE PRECISION
SYSDATE → CURRENT_TIMESTAMP
NVL(a,b) → COALESCE(a,b)
DECODE(col,v,r,...) → CASE WHEN ... END
ROWNUM → LIMIT / ROW_NUMBER() OVER()
CONNECT BY → WITH RECURSIVE CTE
SEQUENCE.NEXTVAL → NEXTVAL('sequence')
ON DELETE CASCADE → ON DELETE CASCADE (same)
VARCHAR2 || VARCHAR2 → same, or CONCAT()

Smart Validator v3 — new checks:
• Trailing comma before ) in CREATE TABLE — detected and reported with line number
• Empty REFERENCES () — FK with empty column list is an error; must be REFERENCES tbl (col)
• Empty constraint column lists — PK/UNIQUE/FK with no columns flagged
• True reserved words unquoted → ERROR with suggestion to quote
• Unreserved keywords (PASSWORD, NAME…) as identifiers → WARNING
• Quoted reserved words (e.g. "DATE", "create") → INFO noting queries must use quotes
• "ROWID" (exact uppercase) as quoted identifier → ERROR (Oracle forbids this)
